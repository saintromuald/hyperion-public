# The pinned ShieldBattery platform

ShieldBattery's platform (accounts, matchmaking, MMR, ladder points, leagues,
seasons), vendored under `engine/tools/shieldbattery/` as the ladder port's
server (`docs/sb-platform-port.md`). The pre-release runs it beside the
engine, and the engine speaks its HTTP/WebSocket APIs directly; the parts of
ShieldBattery that only exist to launch and hook StarCraft: Remastered are
trimmed out.

- Upstream: https://github.com/ShieldBattery/ShieldBattery
- Fork: none yet — create `saintromuald/ShieldBattery` before the first rebase
- Pinned commit: `abdeb8ae23b841e36535b01890c5302347948c06` (upstream master,
  2026-10-31)

## The trim

| Dropped | Why |
|---|---|
| `app/` | the Electron launcher that starts SCR and injects the game DLL; Hyperion's engine is the client (plan Decision 2) |
| `game/` | the Rust DLL that hooks SCR's netcode and reports results; Hyperion reports its own results |
| `integration/` | Playwright tests that drive the Electron app |
| `deployment/` | ShieldBattery's production Kubernetes manifests |
| `server/public/` | the built web client (13 MB); regenerated by the client build (`pnpm build-client`-style scripts, see `package.json`) |

## The Hyperion-specific delta

Changes made to the vendored tree, tracked here so a rebase can re-apply them:

- `.gitignore`: `target/` (Rust build output for `server-rs`; upstream's list
  has no Rust ignores because upstream builds Rust outside this tree).

## Rebasing

Copy a fresh clone at the new rev with the same trim:

    rsync -a --exclude .git --exclude app --exclude game --exclude integration \
        --exclude deployment --exclude server/public \
        <fresh-clone>/ engine/tools/shieldbattery/

then re-apply the delta list above, diff against the previous pinned rev to
catch unintended drops, and run the Phase 1 gate (the scripted two-client
match) before committing.
